# Orrery

An interactive 3D orrery of the solar system in a single page (`index.html`).

- Planet surfaces are painted in code when the page loads (no image files), including Earth's clouds, Jupiter's Great Red Spot and Saturn's rings.
- Positions come from JPL's approximate Keplerian elements, most accurate from 1800 to 2050.
- Drag to orbit, scroll or pinch to zoom, click a planet or its label to focus it. Keys: `1`–`9` planets, `0` or `Esc` the Sun, `M` the Moon, `Space` play/pause, `R` reverse.

Uses three.js r128 from cdnjs. Planet sizes and the Moon's distance are enlarged so they can be seen.
